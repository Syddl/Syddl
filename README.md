  ## About Me

  I am Justine, a full stack developer from the Philippines. I build clean, fast, and user-friendly web applications using
  React, Next.js, TypeScript, and Tailwind CSS on the frontend, with FastAPI, Express.js, Node.js, and modern databases on
  the backend.

  Right now, I am working on an AI-assisted video generation platform, improving automation around script generation,
  narration, visual asset selection, captions, audio, FFmpeg rendering, retry/resume systems, validation, and production
  reliability.
